# QuickServe


A modern and responsive local service-booking platform that connects
customers with trusted service providers for home repair and maintenance
services.

## Features

- Responsive modern UI
- Service category browsing
- Service provider listings
- Provider ratings and pricing
- Search functionality
- Booking workflow
- Customer and provider dashboards
- Mobile-friendly navigation
- Interactive JavaScript features

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
